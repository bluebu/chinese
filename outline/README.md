# 课文要求总表

一册一份的宏观总表：每课一行，**哪篇要背、哪首要默写一眼看到**。要求一律照课后题原话。

```
outline/
  generate_outline.py    生成脚本
  specs/g4a.txt          总表内容（一册一份，按册命名，不按日期）
  sheets/g4a.html|.pdf   A4 打印单，夹在语文书里
  index.html             网页速查页（脚本生成，别手改）
```

**命名和别的栏目不一样**：练习单、打卡单一天一份，所以按 `<日期>.txt`；总表一册只有一份，
所以按册命名 —— `g4a` = 四年级上册。

## 生成

**脚本用相对路径，一律在 `outline/` 目录下运行。**

```bash
python3 generate_outline.py specs/g4a.txt --pdf   # 打印单 HTML + PDF，同时刷新网页速查页
python3 generate_outline.py specs/g4a.txt         # 只出 HTML（先在浏览器看排版）
python3 generate_outline.py --pdf                 # 不给 spec 就用 specs/ 里最新改动的那份
```

或在根目录 `make outline`。一份 spec 出两个东西：`sheets/g4a.pdf`（打印）和 `index.html`（手机上翻）。

## spec 写法

```
title: 课文要求总表
range: 2024 版人教统编版 · 四年级上册 · 第一~第四单元（1~14 课）
note: 手上这份电子课本只到书页 53 ……            # 表格上方的一行小字，交代范围边界

summary: 要背的只有 3 处 | 1 观潮（第 3~4 自然段）、8 古诗三首、12 精卫填海
summary: 要默写的只有 1 首 | 《题西林壁》          # 可重复，进顶部摘要框

[1] 观潮 read=有感情地朗读 recite=第 3~4 自然段 write=14
other: 说课文按什么顺序描写……                     # "其他要求"列

[3*] 现代诗二首 read=反复朗读 write=0             # 课号带 * = 略读课文
[园地一] 日积月累 recite=《赠刘景文》苏轼 write=-

tail: 会不会背 ≠ 会不会写：全册只有《题西林壁》要默写   # 可重复，进底部小结
```

- 四个属性：`read=` 朗读要求、`recite=` 背诵、`copy=` 默写、`write=` 写字数。
  **值可以带空格**（`recite=第 3~4 自然段`），脚本按下一个 `key=` 的位置切。
- `recite=` / `copy=` 不写就是不要求，渲染成淡灰 `—`；写了就上底色加圆点 ●，一眼扫得出。
- `write=0` 或课号带 `*` → 印「只认字」（略读课文不要求写字）；`write=-` → `—`（语文园地行）。
- `recite=待补` 印灰色「待补」，不加圆点 —— 手上课本缺的单元用这个占位，**别凭印象补**。
- `[园地X]` 开头的行自动认成语文园地，课号和课文名换成青色，底色略淡。

## 内容准则

- **要求一律照课后题原话**："有感情地朗读课文。背诵第 3~4 自然段。" 就写这个，
  别自己发明"熟悉""掌握""熟读成诵"——书上没有这些词。
- **背诵和默写分开两列**：书上要求背的不一定要默写。全册 1~14 课只有《题西林壁》写了"默写"。
- **课本没覆盖的单元标「待补」**，不猜、不从别的版本抄。2024 版和 2019 版课次编号不一样
  （《走月亮》2024 版已删，第 2 课是《繁星》），混用会错得很隐蔽。
- 日积月累算"要背"，但和课文背诵分开统计——页头会分别显示「课文要背 N 处」「日积月累 N 处」。

## 排版调整

18 行正好装满一页 A4。行数变多就先缩 `td.other` 的字号／行距，再收 `th,td` 的 padding；
底部小结靠 `.tail{margin-top:auto}` 钉在页底，别删。改完重新生成，
**Read 生成的 PDF 看排版**，别凭 HTML 源码想象。
