# 抽查单（A4 打印）

学完一课／一单元后，家长照着单子问一遍，十分钟知道哪儿没记住。**一张单子一页。**

```
check/
  generate_check.py         生成脚本
  specs/<日期>.txt          这次要查什么（手写，一次一份）
  sheets/<日期>.html|.pdf   生成的抽查单（_answers 后缀是家长版）
```

两版分开印：

- **题面版**（`20260825.pdf`）给孩子——答案不印，动笔的题空着让他写。
- **家长版**（`20260825_answers.pdf`）给家长——答案全印，照着问、照着改。家长版不进目录页。

## 生成

**脚本用相对路径，一律在 `check/` 目录下运行。**

```bash
python3 generate_check.py specs/20260825.txt --pdf              # 题面版 HTML + PDF
python3 generate_check.py specs/20260825.txt                    # 只出 HTML（先在浏览器看排版）
python3 generate_check.py --pdf                                 # 不给 spec 就用 specs/ 里最新改动的那份
python3 generate_check.py specs/20260825.txt --answers --pdf     # 家长版（答案全印）
```

或在根目录 `make check`，一次出两版。PDF 由无头 Chrome 导出，A4 竖版，直接打印。

## spec 写法

```
# 井号开头是注释
title: 抽查单                       # 页头标题
range: 四年级上册 · 第一~第四单元    # 页头副标题，查的是哪个范围
hint: 家长照着念，孩子口头答。        # 使用说明，只印在家长版上
minutes: 10                        # 页头显示的总时长
memo: 错在哪儿，记一笔——            # 页底错题格里的提示语，只印在题面版上

[多音字] 只读，不写 time=2 pass=错 ≤ 1 个
note: 教材里标蓝的字，按课文语境定音。      # 块内灰色小字说明
薄雾=bó, 隆隆的响声=lóng, 荧光屏=píng     # 网格项：题面=答案，两列排

[默写] 《题西林壁》苏轼 time=3 pass=零错字
lines: 4                                  # 留 4 条空白横线给孩子写
answer: 横看成岭侧成峰……　易错字：侧、峰、庐、缘

[复述] 用自己的话说 time=2 pass=三要素齐
ask: 三句话讲完《普罗米修斯》 | 起因：……；经过：……；结果：……
```

- `[题块]` 后面跟副标题和两个属性：`time=` 这块几分钟、`pass=` 过关线。
  **`pass=` 的值可以带空格，所以要写在最后**。
- 块内四种行：
  - `note:` 块说明（灰色小字，两版都印）
  - `汉字=答案` 网格项，两列排，一项一个勾选框；用 `,`／`，`／`、` 分隔，可跨行写
  - `ask: 题面 | 参考答案` 整行问答，题面或答案长的用它
  - `lines: N` 留 N 条空白横线；配 `answer:` 写参考答案
- 勾选框、`time=`、`pass=` 两版都印；`=` 后的答案、`ask` 的答案、`answer:` **只印在家长版上**。

## 内容准则

- **要求一律照课后题原话**（"背诵第 3~4 自然段""默写《题西林壁》"），不自己发明"熟读""掌握"这类
  书上没有的要求。拿不准就翻教材，别凭印象。
- **`pass=` 要写得能一眼判定**：`错 ≤ 1 个`、`零错字`、`三要素齐` 可以；`基本掌握` 不行。
- **以口头题为主**（读音、背诵、复述）——口头比笔头快得多，十分钟才问得完。动笔的题超过两三项，
  就该去 `practice/` 出一张正经的默写单，别把抽查单撑成练习单。

## 排版调整

一张单子 **5~6 个题块**正好装满一页 A4。题面版下半页的空白由页底错题格（`memo:`）自动吃掉；
家长版答案多、本来就满，所以不印错题格。块多了会溢出到第二页——删块，或把 `ask:` 的答案写短些。
改完重新生成，**Read 生成的 PDF 看排版**，别凭 HTML 源码想象。
