# 抽查单（A4 打印）

学完一课，家长照着单子问一遍，十分钟知道哪儿没记住。**一课一张，一张一页。**

```
check/
  generate_check.py         生成脚本
  specs/01.txt              第 1 课的抽查内容（按课号命名）
  specs/03y.txt             语文园地一（排在第 3 课后面）
  sheets/01.html|.pdf       生成的抽查单（_answers 后缀是家长版）
```

**spec 按课号命名**：`01.txt` = 第 1 课，`08.txt` = 第 8 课。学完哪课打印哪张，
别把几课混在一张上——混着问，孩子累，也看不出是哪一课没记住。

**语文园地用 `<课号>y`，严格照课本目录排在它所属单元的最后一课后面**：
`03y` = 语文园地一（第一单元末，第 3 课后）、`07y` = 语文园地二、`10y` = 语文园地三、
`14y` = 语文园地四。目录页就按这个顺序列，不要把园地都堆到最后。

两版分开印：

- **题面版**（`01.pdf`）给孩子——答案不印，动笔的题空着让他写，页底有错题格。
- **家长版**（`01_answers.pdf`）给家长——答案全印，照着问、照着改。家长版不进目录页，
  听写的横线也压到一行（家长不用写字，留一行记错字够了）。

## 生成

**脚本用相对路径，一律在 `check/` 目录下运行。**

```bash
python3 generate_check.py --all --pdf                     # 每课都出（题面版 + 家长版）
python3 generate_check.py specs/01.txt --pdf              # 只出第 1 课，题面版
python3 generate_check.py specs/01.txt                    # 只出 HTML（先在浏览器看排版）
python3 generate_check.py specs/01.txt --answers --pdf    # 家长版（答案全印）
python3 generate_check.py --pdf                           # 不给 spec 就用 specs/ 里最新改动的那份
```

或在根目录 `make check` 一次出全部。PDF 由无头 Chrome 导出，A4 竖版，直接打印。

## spec 写法

```
# 井号开头是注释
title: 抽查单                       # 页头标题
range: 第 1 课　观潮                 # 页头副标题
lesson: 观潮                        # 课文名，目录页上显示
hint: 家长照着念，孩子口头答。        # 使用说明，只印在家长版上
minutes: 10                        # 页头显示的总时长
memo: 错在哪儿，记一笔——            # 页底错题格的提示语，只印在题面版上

[读准] 只读，不写 time=2 pass=错 ≤ 1 个
note: 这十个是本课最容易读错的。          # 块内灰色小字说明
薄雾=bó, 闷雷滚动=mèn, 横贯江面=guàn     # 网格项：题面=答案，两列排

[听写] 家长报词，孩子写在横线上 time=2 pass=错 ≤ 1 个
lines: 3                                  # 留 3 条横线（家长版自动压到 1 条）
answer: 可报：观潮、根据、大堤、越过……

[背诵] 第 3~4 自然段（书上要求） time=3 pass=不打断、不提示
ask: 第 3 段——「午后一点左右……」往下背 | 好像闷雷滚动 → 顿时人声鼎沸 → 潮来了 → ……
```

- `[题块]` 后面跟副标题和两个属性：`time=` 这块几分钟、`pass=` 过关线。
  **`pass=` 的值可以带空格，所以要写在最后**。
- 块内四种行：
  - `note:` 块说明（灰色小字，两版都印）
  - `汉字=答案` 网格项，两列排，一项一个勾选框；用 `,`／`，`／`、` 分隔，可跨行写
  - `ask: 题面 | 参考答案` 整行问答，题面或答案长的用它
  - `lines: N` 留 N 条空白横线；配 `answer:` 写参考答案
- 勾选框、`time=`、`pass=` 两版都印；`=` 后的答案、`ask` 的答案、`answer:` **只印在家长版上**。
- **背诵题的答案别抄整段原文**，写成「关键节点 → 关键节点」的链条——家长扫一眼就知道
  孩子漏了哪句，原文抄上去反而占满一页还不好核对。

## 内容准则

- **要求一律照课后题原话**（"背诵第 3~4 自然段"），不自己发明"熟读""掌握"这类书上没有的要求。
  这一课到底要不要背、要不要默写，先查 `outline/` 的要求总表。
- **`pass=` 要写得能一眼判定**：`错 ≤ 1 个`、`零错字`、`顺序说对` 可以；`基本掌握` 不行。
- **以口头题为主**（读音、背诵、复述）——口头比笔头快得多，十分钟才问得完。动笔的题超过两三项，
  就该去 `practice/` 出一张正经的默写单，别把抽查单撑成练习单。
- 一课的抽查内容大致是：**读准（多音字/易错音）→ 背诵（书上要求的才有）→ 听写（本课写字表抽几个）
  → 课后题（口头）→ 词语意思**，5 个题块 15~20 项，正好一页十分钟。

## 排版调整

**字号是给孩子看的，别调小**：题面楷体 20px、块名 18px，家长版的答案 12.5px。
一张单子 5~6 个题块正好装满一页 A4；题面版下半页的空白由页底错题格（`memo:`）自动吃掉，
家长版答案多、本来就满，所以不印错题格。
块多了会溢出到第二页——删块，或把 `ask:` 的答案写短些。
改完重新生成，**Read 生成的 PDF 看排版**，别凭 HTML 源码想象。
