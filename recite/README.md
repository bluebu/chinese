# 朗读打卡（A4 打印）

要背的课文做成打印单：大字排版，底下一排圈，读一遍涂一个。**一篇课文一页。**

```
recite/
  generate_recite.py        生成脚本
  specs/<日期>.txt          当天要读的篇目（手写，一天一份）
  sheets/<日期>.html|.pdf   生成的打卡单
```

## 生成

**脚本用相对路径，一律在 `recite/` 目录下运行。**

```bash
python3 generate_recite.py specs/20260825.txt --pdf   # HTML + PDF
python3 generate_recite.py specs/20260825.txt         # 只出 HTML（先在浏览器看排版）
python3 generate_recite.py --pdf                      # 不给 spec 就用 specs/ 里最新改动的那份
```

PDF 由无头 Chrome 导出，A4 竖版，直接打印。

## spec 写法

```
# 井号开头是注释
title: 朗读打卡                     # 页头标题
hint: 大声读一遍，涂一个圈。         # 备用说明，暂时只写在 spec 里
times: 10                          # 每篇读几遍（几个圈），默认 10
size: 27                           # 正文字号（px），默认 17
# date: 8月25日                     # 页头日期。一般别写——同一份要读好几天，
#                                   # 日期让孩子填页头右边那栏

[观潮] 第 3-4 自然段 author=赵宗成、朱明元 times=10
task: 今天读 10 遍，以后要背诵。
午后一点左右，从远处传来隆隆的响声，好像闷雷滚动。顿时人声鼎(dǐng)沸(fèi)……

那条白线很快地向我们移来，逐渐拉长，变粗，横贯(guàn)江面。……

[精卫填海] 文言文 author=《山海经·北山经》
task: 明后天默写、背诵。
炎帝之少(shào)女，名曰(yuē)女娃。……
note: 炎帝的小女儿，名叫女娃。……      # 文言文的意思，印在正文下面的小框里
```

- `[篇名]` 后面跟副标题（`第 3-4 自然段`）和属性：`author=` 作者、`times=` 读几遍、`size=` 正文字号。
  `times` / `size` 不写就用文件头的默认值。
- `task:` 是正文上方那条红色任务提示；`note:` 是正文下方的意思框（文言文用，白话课文一般不用）。
- 其余的行都是正文，**空行分段**；spec 里为了好读断行的同一段会自动接回去。
- **正文里 `字(拼音)` 会排成小字注音**（`鼎(dǐng)沸(fèi)`）。拼音只跟前面那**一个**汉字，
  所以两个字都要标就一个字一个字写。只标难字，别满篇都标。

## 排版调整

**三篇统一 27px**（文件头写一次，别再逐篇 `size=`）——朗读单字大才好读，各篇字号一样才不觉得
是两份东西。27px 下最长的《观潮》3-4 段正好一页装满，再长的课文才需要调小；短课文下半页留白是正常的。改完重新生成，**Read 生成的 PDF 看排版**，别凭 HTML 源码想象。
